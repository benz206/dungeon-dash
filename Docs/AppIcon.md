# Dungeon Dash app icon

Asset: `Assets/Art/Branding/AppIcon.png`.

Generated September 8, 2026 with the built-in image generation tool. The original
generated image is preserved without pixel edits. Unity imports it as an opaque
texture and generates the sizes required by the platform. The image depicts a
silver knight, cyan visor, crimson scarf, and a gold-lit dungeon arch.

`BrandingTools.Apply` assigns the icon before Mac preview builds and iOS exports.
The iOS exporter sets **Dungeon Dash** as `CFBundleDisplayName` in the exported
Info.plist, keeping Unity's internal product name and existing save location stable.
Icon assignment uses Unity's documented
[platform icon API](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/PlayerSettings.SetPlatformIcons.html).
